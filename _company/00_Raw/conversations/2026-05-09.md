## 1. 브랜드 컬러 팔레트 (Color Palette)

kmongland의 브랜드 정체성인 '학습', '신뢰', '편안함'을 반영하여 차분하면서도 집중도를 높이는 색상 조합을 확정했습니다.

| 역할 | 색상 이름 | HEX 코드 | RGB | 사용 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (메인)** | kmongland Blue | `#3B82F6` | (59, 130, 246) | CTA 버튼, 핵심 링크, 활성화 상태 |
| **Secondary (보조)** | Soft Gray | `#F3F4F6` | (243, 244, 246) | 배경, 카드 배경, 섹션 구분 |
| **Accent (강조)** | Warm Orange | `#F59E0B` | (245, 158, 11) | 강조 CTA, 알림, 중요한 정보 표시 |
| **Text (본문)** | Dark Text | `#1F2937` | (31, 41, 55) | 본문 텍스트, 제목, 주요 헤딩 |
| **Background (배경)**| Light White | `#FFFFFF` | (255, 255, 255) | 페이지 배경 |

**💡 컬러 사용 규칙:**
*   **Primary (`#3B82F6`):** 상호작용 요소(클릭 시)에 사용하여 사용자 행동을 유도합니다.
*   **Accent (`#F59E0B`):** 중요한 정보나 긍정적인 피드백에 사용하며, 시각적 계층 구조를 부여합니다.
*   **Soft Gray (`#F3F4F6`):** 콘텐츠 블록이나 카드에 사용하여 정보를 명확하게 분리하고 가독성을 높입니다.

## 2. 타이포그래피 시스템 (Typography System)

가독성과 전문성을 동시에 확보하기 위해 산세리프 계열 폰트를 사용하며, 정보의 위계를 명확히 구분합니다.

**Font Family:** Inter (시스템 기본 폰트 또는 웹 안전성이 높은 대체 폰트)

| 역할 | 폰트 크기 (px/rem) | 폰트 두께 (Weight) | Line Height (행 높이) | 사용 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **H1 (페이지 제목)** | 3.5rem (56px) | Bold (700) | 1.2 | 메인 페이지 헤드라인 |
| **H2 (섹션 제목)** | 2.25rem (36px) | SemiBold (600) | 1.3 | 주요 섹션 제목 |
| **H3 (소제목)** | 1.75rem (28px) | Medium (500) | 1.4 | 카드 내부 제목, 부제목 |
| **Body Large** | 1.125rem (18px) | Regular (400) | 1.6 | 본문 내용 강조 |
| **Body Base** | 1rem (16px) | Regular (400) | 1.6 | 일반 본문 텍스트 |
| **Caption/Meta** | 0.875rem (14px) | Medium (500) | 1.5 | 저작권, 메타 정보, 작은 설명 |

**💡 타이포그래피 사용 규칙:**
*   **계층 구조:** H1 > H2 > H3 순으로 명확하게 사용하여 시선 흐름을 통제합니다.
*   **가독성:** Body Base의 Line Height는 1.6을 유지하여 장문의 학습 콘텐츠도 편안하게 읽을 수 있도록 합니다.

## 3. 레이아웃 및 간격 시스템 (Layout & Spacing System)

일관된 그리드와 여백 규칙을 적용하여 안정적인 사용자 경험을 제공합니다. 모든 측정 단위는 **rem**을 기본으로 사용합니다.

**Spacing Scale (간격):**
*   **S (Small):** 0.5rem (8px) - 미세 조정, 좁은 간격
*   **M (Medium):** 1rem (16px) - 일반적인 요소 간의 여백
*   **L (Large):** 1.5rem (24px) - 섹션 구분, 주요 블록 사이의 여백
*   **XL (Extra Large):** 3rem (48px) - 페이지 전체 섹션 분리

**Border Radius (모서리 둥글기):**
*   **Default:** 8px (카드, 버튼)
*   **Large:** 12px (주요 컨테이너)

**💡 레이아웃 적용 예시:**
*   페이지 배경: `Background` (`#FFFFFF`)
*   콘텐츠 카드 배경: `Soft Gray` (`#F3F4F6`), Border Radius: `8px`
*   주요 CTA 버튼 배경: `Primary` (`#3B82F6`), 텍스트 색상: `Light White`
